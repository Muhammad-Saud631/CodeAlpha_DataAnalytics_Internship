# 📊 Task 2 - Exploratory Data Analysis (EDA)

This project was completed as part of the CodeAlpha Data Analytics Internship.

## 📌 Objective
Perform Exploratory Data Analysis on a scraped books dataset to identify trends, patterns, and insights.

## 🛠️ Tools & Libraries
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📂 Analysis Performed
- Data Structure Analysis
- Data Type Checking
- Missing Value Detection
- Statistical Summary
- Rating Distribution Analysis
- Price Analysis
- Data Visualization

## 📊 Key Insights
- Most books had Three-star ratings.
- No missing values were found.
- Book prices varied significantly.
