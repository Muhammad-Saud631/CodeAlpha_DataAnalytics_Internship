To convert raw book dataset into meaningful visual insights using Python.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib

## 📊 Visualizations Created
- Rating Distribution Chart

## 📈 Key Insights
- Most books have mid-level ratings.
- Price distribution is mostly balanced.
- Some correlation exists between rating and price.
