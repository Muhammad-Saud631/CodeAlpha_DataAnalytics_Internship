# 📊 Task 1 - Web Scraping

This project was completed as part of the CodeAlpha Data Analytics Internship.

## 📌 Project Objective
The objective of this project is to extract data from a public website using Python web scraping techniques and create a structured dataset for analysis.

## 🌐 Website Used
Books to Scrape

## 🛠️ Technologies & Libraries
- Python
- Requests
- BeautifulSoup
- Pandas
- Jupyter Notebook

## 📂 Data Extracted
The following data was collected from the website:
- Book Titles
- Prices
- Ratings

## ⚙️ Process
1. Connected to the website using Requests library
2. Parsed HTML content using BeautifulSoup
3. Extracted required book information
4. Stored data into lists
5. Created dataset using Pandas
6. Exported dataset as CSV file

## 📁 Output
- Structured CSV Dataset
- Jupyter Notebook File
