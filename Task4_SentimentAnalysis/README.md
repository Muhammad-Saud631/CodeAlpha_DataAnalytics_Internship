# 🧠 Task 4 - Sentiment Analysis

This project is part of CodeAlpha Data Analytics Internship.

## 🎯 Objective
To analyze text reviews and classify them into Positive, Negative, and Neutral sentiments.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib

## 📌 Approach
- Created sample review dataset
- Defined positive and negative keyword lexicons
- Applied rule-based sentiment classification
- Visualized sentiment distribution

## 📊 Output
- Sentiment labels for each review
- Bar/Pie chart visualization

## 📈 Insights
- Mixed sentiment pattern observed
- Useful for understanding customer opinion trends
